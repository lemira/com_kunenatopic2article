# Обработка ссылок на видео в компоненте

## Обзор

Компонент автоматически распознает и обрабатывает ссылки на видео из различных платформ при переносе постов Kunena в статьи Joomla. Ссылки видео в статьях также работают в адаптивном дизайне на мобильных устройствах.

## Принцип работы

### Компонент может обрабатывать видеоссылки двумя способами - с использованием плагина Joomla AllVideos или без него.

Для Joomla 5 AllVideos по-прежнему рекомендуется: компонент автоматически определяет, включен ли плагин AllVideos. Если плагин включен, компонент преобразует ссылки в теги AllVideos, которые в рамках возможностей плагина изображаются в статье как окна видео. В результате соответствующие видео можно проигрывать прямо в статье.

Для Joomla 6 интеграция AllVideos отключается автоматически, пока JoomlaWorks официально не объявил совместимость AllVideos с Joomla 6. В этом режиме компонент не генерирует теги AllVideos и использует собственные iframe/стилизованные ссылки.

Если AllVideos не установлен или установлен, но не включен:
- При вызове компонента администратор получает сообщение:
  *Плагин AllVideos не установлен в Joomla или не включен. Рекомендуется установить AllVideos от JoomlaWorks. Тогда в создаваемых статьях видео, если они есть в теме, будут отображаться как плееры, а не ссылки*
- Для YouTube и Vimeo генерируются собственные iframe для встраивания видео. Таким образом видео с этих платформ отображается непосредственно в статье
- Для остальных платформ в статье создаются кликабельные ссылки в специальном формате, с иконкой камеры 📹. При наведении курсора на такую ссылку показывается полезная всплывающая подсказка.

### Особые случаи обработки:

**Facebook Video:**
Всегда отображается как стилизованная ссылка, так как Facebook блокирует встраивание видео в iframe по соображениям безопасности.

**YouTube с временными метками:**
Если ссылка содержит метку времени (например, `?t=42s`), компонент создает собственный iframe вместо использования AllVideos, чтобы сохранить начало воспроизведения с указанного момента.

## Установка AllVideos (рекомендуется для Joomla 5)

1. Скачайте плагин AllVideos с JED (https://extensions.joomla.org/)
2. Установите через Система → Установка → Расширения
3. Активируйте плагин в Система → Плагины → Content - AllVideos
4. На Joomla 5 компонент автоматически определит наличие плагина и будет использовать его

Преимущества использования AllVideos:
- Поддержка множества видеоплатформ
- Единый стиль отображения всех видео
- Автоматические обновления при изменении API платформ
- Дополнительные настройки отображения (размер, выравнивание и т.д.)
 
## Поддержка платформ

**YouTube и Vimeo:**
- Всегда окно через собственный iframe или плагин AllVideos

**Dailymotion и SoundCloud:**
- С AllVideos: окно через плагин
- Без AllVideos: стилизованная ссылка

**Facebook:**
- Всегда стилизованная ссылка (из-за ограничений Facebook)

## Визуальное оформление

**Видео-окна (iframe):**
- Автоматически адаптируются под ширину экрана
- Имеют закругленные углы и тень для визуального выделения
- Стилизация через файл `kun_p2a.css`

**Стилизованные ссылки:**
- Отображаются с иконкой видеокамеры 📹
- Имеют синий градиентный фон
- При наведении курсора показывают всплывающую подсказку
- Анимация при взаимодействии (поднятие и увеличение тени)

## Устранение проблем

Из-за разнообразия видеоплатформ и плейеров видеоссылки в статьях требуют особого внимания. Если не очевидно, что ссылка перенесена в статью и работает правильно, советуем проверять ее, сравнивая с оригиналом в посте Кунена.

**Если видео не отображается:**
1. Проверьте корректность URL в исходном посте Kunena
2. Убедитесь, что видео не было удалено владельцем
3. Для Facebook: убедитесь, что видео публичное (не для друзей)
4. Для YouTube: проверьте, что видео не заблокировано в вашем регионе

**Если метка времени YouTube не работает:**
- Формат должен быть: `?t=42s`, `?t=1m30s` или ?t=1h2m3s

## Возможные улучшения

- Добавление поддержки других популярных платформ (TikTok, Instagram и т.д.)
- Настройка размеров iframe в параметрах компонента (вместо css)
- Возможность выбора поведения для каждой платформы отдельно

## Структурированный список поддерживаемых форматов

### YouTube
✅ Стандартные:
```
https://www.youtube.com/watch?v=VIDEO_ID
https://youtube.com/watch?v=VIDEO_ID
https://youtu.be/VIDEO_ID
```

✅ Мобильная версия:
```
https://m.youtube.com/watch?v=VIDEO_ID
```

✅ С временной меткой (разные форматы):
```
https://www.youtube.com/watch?v=VIDEO_ID&t=42s
https://youtu.be/VIDEO_ID?t=90
https://youtu.be/VIDEO_ID?t=1m30s
```

✅ В BBCode тегах:
```
[video]https://www.youtube.com/watch?v=VIDEO_ID[/video]
[url=https://youtu.be/VIDEO_ID]Текст ссылки[/url]
```

✅ Видео из плейлиста:
```
https://www.youtube.com/watch?v=VIDEO_ID&list=PLAYLIST_ID
Обрабатывается только указанное видео (VIDEO_ID), плейлист игнорируется.

```

### Vimeo
✅ Стандартные:
```
https://vimeo.com/VIDEO_ID
https://www.vimeo.com/VIDEO_ID
```

✅ Embed-ссылки:
```
https://player.vimeo.com/video/VIDEO_ID
```

✅ В BBCode тегах:
```
[video]https://vimeo.com/VIDEO_ID[/video]
[url=https://vimeo.com/VIDEO_ID]Текст ссылки[/url]
```

### Dailymotion
✅ Стандартные:
```
https://www.dailymotion.com/video/VIDEO_ID
https://dailymotion.com/video/VIDEO_ID
```

✅ Короткие ссылки:
```
https://dai.ly/VIDEO_ID
```

✅ Старый формат с названием:
```
https://www.dailymotion.com/video/VIDEO_ID_video-title
```

### Facebook
✅ Стандартные (только ссылки, не embed):
```
https://www.facebook.com/watch/?v=VIDEO_ID
https://www.facebook.com/username/videos/VIDEO_ID/
https://facebook.com/watch/?v=VIDEO_ID
```

✅ Мобильная версия:
```
https://m.facebook.com/watch/?v=VIDEO_ID
```

✅ Короткие ссылки:
```
https://fb.watch/SHORT_CODE/
```

✅ В BBCode тегах:
```
[url=https://www.facebook.com/watch/?v=VIDEO_ID]Текст ссылки[/url]
```

### SoundCloud
✅ Плейлисты:
```
https://soundcloud.com/user/sets/playlist-name
```

✅ Отдельные треки:
```
https://soundcloud.com/user/track-name
```

✅ С параметрами:
```
https://soundcloud.com/user/track?in=user/sets/playlist
```

### Смешанные случаи
✅ Несколько ссылок в одной строке:
```
YouTube: https://youtu.be/VIDEO_ID и Vimeo: https://vimeo.com/VIDEO_ID
```

✅ Ссылка внутри текста:
```
Посмотрите это видео https://youtube.com/watch?v=VIDEO_ID на YouTube
```

✅ BBCode с разными текстами:
```
[url=https://youtube.com/watch?v=VIDEO_ID]Описание видео[/url]
```

### Не поддерживается
❌ Главные страницы платформ:
```
https://youtube.com
https://facebook.com
https://vimeo.com
```

❌ Неполные/битые ссылки:
```
youtube.com/watch?v=
https://youtu.be/
```

❌ Текст, похожий на ссылку (без протокола):
```
Посетите youtube.com для просмотра
```
