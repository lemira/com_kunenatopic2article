# Kunena Topic to Article

*Документация на английском:* [🇬🇧 English](../README.md)

Компонент для автоматического создания статей Joomla на основе тем форума Kunena. 
Разработан для Joomla 5 и Kunena 6.x. Работает на Joomla 6 и Kunena 7.

[📖 Связи постов в Кунена, блок информационных строк, парсинг, языки](FUNCTIONALITY.ru.md) | [ℹ️ Письма о создании статей, кодировка БД, плагин](ADDITIONAL.ru.md) | [ℹ️ Обработка ссылок на видео](VIDEOLINKS.ru.md)


## 🚀 Основная информация

### 1.1. Назначение
Компонент Kunena Topic to Article (`kunenatopic2article`) автоматически генерирует материалы Joomla на основе тем форума Kunena. 
- ✅ Требует Joomla 5 и Kunena 6.x
- ✅ Работает в административной части Joomla
- ✅ Протестирован на Joomla 5.4 / Kunena 6.3.10

### 1.2. Параметры компонента

#### 📄 Параметры создаваемой статьи
- **ID темы** (номер первого сообщения темы)¹
- **Категория статьи** (выбирается из выпадающего списка категорий статей сайта)
- **Схема переноса сообщений** (последовательная или древовидная), см. п.7 
- **Максимальный размер статьи** (число символов, по умолчанию 40000), см. п. 2.2.

#### ℹ️ Параметры блока информационных строк
(имеют значения "Скрыть" / "Показать" кроме двух последних)
- **Автор сообщения** - определяется по теме 
- **Дата создания сообщения** - берется из поста
- **Время создания сообщения** - берется из поста
- **Заголовок сообщения** - берется из поста²
- **Ссылка на сообщение в форуме** - показывает индекс сообщения как ссылку, см. п. 4.1
- **Связь сообщений** - показывает связь сообщения и его родительского сообщения (например, #42 ⟸ #35)
- **Количество символов напоминания** - количество показываемых символов из родительского сообщения (0-300)
- **Игнорируемые авторы** - имена пользователей (разделённые запятыми), чьи сообщения не переносятся в создаваемые статьи

_¹ ID отображается в правом верхнем углу сообщения после знака # при включенной в Kunena опции "Показать реальный ID поста"  
 ² В настоящее время Kunena определяет заголовок сообщения как "Заголовок темы" или RE:"Заголовок темы"_

### 🎨 Стили CSS
Стили определяют вид статей (по умолчанию - практически стандартный) и оформление блока информационных строк. Файл стилей /media/com_kunenatopic2article/css/kun_p2a.css можно редактировать в com_kunenatopic2article.zip или прямо на сервере без переустановки компонента.

Текущий файл CSS встраивается в HTML каждой создаваемой статьи. Это обеспечивает индивидуальную настройку стилей отдельных статей или групп статей, отсутствие влияния изменений CSS компонента на ранее созданные статьи и независимость от наличия установленного компонента.

Редактирование встроенного в статью CSS описано в файле docs/FUNCTIONALITY.ru.md документации в разделе 4.3. Если вы уже пользовались компонентом версии 1, рекомендуется посмотреть раздел для релиза 2.0.0 в файле CHANGELOG.md.

### 1.3. Установка
1. Установите компонент из файла `com_kunenatopic2article.zip` через менеджер расширений Joomla
2. Компонент автоматически создаст таблицу `kunenatopic2article_params` (одна строка) в базе данных
3. Дополнительно доступен [плагин точного позиционирования](ADDITIONAL.ru.md#8-плагин-точного-позиционирования), см. п. 8.

## ⚙️ Основные сведения о функционировании компонента

### 2.1. Управление компонентом
При вызове компонента доступны четыре кнопки:

| Кнопка | Назначение |
|--------|------------|
| ✅ **Запомнить** | Проверяет и сохраняет параметры |
| 🔄 **Сбросить параметры** | Возвращает настройки по умолчанию |
| 👁️ **Предпросмотр** | Показывает два первых поста с блоком информационных строк |
| 🚀 **Создать статьи** | Формирует одну или несколько статей на основе темы |

> Кнопки "Предпросмотр" и "Создать статьи" активируются после успешного сохранения параметров. Для использвания функции "Предпросмотр" пользователь должен быть авторизован на сайте.

![Форма параметров компонента и кнопок управления](images/Main_Component_Form.png "Форма параметров компонента и кнопок управления")

### 2.2. Создание статей
- Автором статей назначается автор темы
- Первая статья получает заголовок "Тема"
- При превышении лимита размера создаются статьи с нумерацией: «Тема. Часть 2», «Тема. Часть 3» и т. д.
- Если какой-то пост превышает максимальный размер, создаётся статья только с этим постом

### 2.3. Служебные строки
В начале каждой статьи размещается информация:
- ℹ️ *"Данная статья автоматически создана из аналогичной темы форума Kunena данного сайта."*
- ⚠️ *"После создания данной статьи и статья, и сообщения в теме могут редактироваться. Поэтому соответствие содержания и оформления статьи и темы может нарушиться."*

### 2.4. Фильтрация постов
В статьи переносятся только:
- Опубликованные посты (`hold = 0`)
- Посты авторов, не указанных в "Игнорируемые авторы"

### 2.5. Блок информационных строк
Выводится перед каждым постом, если включён хотя бы один из параметров блока. При отключении всех параметров сообщения разделяет малозаметная черта. См. п. 4.

### 2.6. Сохранение разметки
- Все ссылки сохраняются
- «Голые» (без поясняющего текста) URL сокращаются до 50 символов
- Изображения-вложения копируются как ссылки на эти вложения в папках Кунена
- См. также п. 5 [Парсинг](FUNCTIONALITY.ru.md#5-парсинг)

## 📊 Результаты создания статей

### 3.1. Отчёт о выполнении
После обработки темы показываются:
- **Созданные статьи** - список с ID и наименованиями статей, а также ссылками на них
- **Отправленные уведомления** - перечень email-адресов, на которые компонент отправил письма о создании статей. См. также п. 10.

![Форма результатов создания статей](images/Article_result.png "Форма результатов создания статей")
### 3.2. Варианты дальнейших действий
Ниже списка статей имеются две кнопки:
- **🔄 Продолжить работу** - открывает форму с сохранёнными параметрами (сбрасывается только ID темы)
- **🏁 Завершить работу** - завершает текущую сессию

### 3.3. Связь между статьями и темой
Созданные статьи и сообщения в теме после работы компонента "живут своей жизнью" и могут редактироваться независимо. Исключение - ссылки в статьях на индексы сообщений, если они созданы. При клике на такую ссылку в соседней вкладке браузера открывается соответствующее сообщение на форуме. Если пост удалён после создания статьи, ссылка может перестать работать.
